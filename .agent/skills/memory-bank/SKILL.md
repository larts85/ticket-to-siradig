# Memory Bank Guidelines

The memory bank consists of markdown files that track the current state, goals, and history of the project. This serves as the single source of truth for context across sessions.

## Core Principles
1. Update files frequently to capture changes in the project.
2. Maintain clear, concise logs of what has been accomplished.
3. Use the structure to manage complex task breakdowns.
4. Keep the status files aligned with reality.

## File Structure
- `activeContext.md`: Current focus and goals.
- `progress.md`: Historical log of updates.
- `productContext.md`: Description of the project's purpose and scope.
- `systemPatterns.md`: Architectural decisions and recurring patterns.
- `techContext.md`: Technical stacks and environment details.

## Workflow Rules
- Update the memory bank AFTER major milestones.
- Do not let the files become obsolete or disconnected from code.
- Always check the memory bank AT THE START of a session.
